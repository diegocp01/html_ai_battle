## 🎯 Original Prompt

Create a simulation of a 'Double Pendulum' (a pendulum attached to the end of another pendulum) using HTML/CSS/JS. It needs to use realistic physics equations for chaotic motion, not just random movement. The tip of the second pendulum should leave a trailing neon path that fades over time so we can see the chaotic pattern it draws.
